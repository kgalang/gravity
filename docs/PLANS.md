# Planning Model

## Plan Types
1. Lightweight plans for small, single-file changes.
2. Active execution plans for multi-step or risky changes.
3. Completed plans archived for historical context.

## Source of Truth
- Active: `docs/plans/active/`
- Completed: `docs/plans/completed/`
- Status board: `docs/checkpoints/mvp-status.md`
- Debt inventory: `docs/tech-debt-tracker.md`
