# Design Beliefs

## Core Beliefs
1. The platform matters more than any single agent.
2. Durable state ownership must remain explicit.
3. Skills and memory are product surface, not hidden internals.
4. Architecture should optimize for agent legibility and human auditability.
5. Every new capability should lower the cost of the next agent.

## Non-Goals for MVP
1. Perfect security enforcement in week one.
2. Full control plane UI before runtime primitives are stable.
3. Premature scaling complexity.
