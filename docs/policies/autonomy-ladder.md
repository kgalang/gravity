# Autonomy Ladder

Use phased autonomy so quality does not regress as throughput rises.

## Levels
1. Level 0: agent drafts only, human edits and executes.
2. Level 1: agent writes code and docs, human runs checks and merges.
3. Level 2: agent writes code/docs and runs checks; human reviews only failing or high-risk areas.
4. Level 3: agent can merge low-risk scoped changes when all gates pass.
5. Level 4: agent handles routine maintenance automatically with periodic human audit.

## Current Level
- Default: Level 1.
- Goal for stable maintenance tasks: Level 2.
